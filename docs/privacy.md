# Privacy

- Fully offline; no analytics, telemetry, crash upload, advertising, or update service.
- Selection access is attempted only after the user presses the lookup shortcut.
- Clipboard fallback must save and restore the prior pasteboard where possible and must not operate in secure input fields.
- Queries, selected text, clipboard contents, and note bodies are not persisted in logs.
- Dictionary packages and the selected Obsidian note remain user-owned files at their existing paths.
