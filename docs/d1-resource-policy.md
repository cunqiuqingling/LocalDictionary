# D1 开放词典资源准入规则

本文只定义未来开放词典资源的审核与分类规则。当前仓库不收录实际资源，不提供资源清单或下载功能，也不创建 `resources.json`。

## 必填审核记录

未来每个候选资源至少记录：

- `resourceID`
- 名称
- 版本
- 语言
- 数据来源
- 权利人或维护者
- 官方项目页面
- 官方下载页面
- 许可证名称
- 许可证版本
- 原始许可证文件或官方条款
- 是否允许重新分发
- 是否允许镜像
- 是否允许修改
- 是否允许格式转换
- 是否允许商业使用
- 是否要求署名
- 是否要求 Share-Alike
- 是否要求保留 NOTICE
- 是否存在数据库权利限制
- 是否存在文本内容版权限制
- App 是否可直接托管
- 是否只能跳转原站
- 文件 SHA-256
- 文件大小
- 审核日期
- 审核依据
- 最后复核日期

软件代码许可证、数据库权利和词典文本版权必须分别审核。软件工具允许读取某种格式，不表示该格式中的词典数据可被镜像、转换或再分发。

## 分类

### A：可由项目托管或镜像

许可证和权利链明确，允许 LocalDictionary 直接托管或镜像，并且项目能够落实署名、许可证传播、NOTICE、Share-Alike 或其他适用义务。

Share-Alike 资源不得自动归入 A；必须逐项确认传播范围、格式转换后义务及与分发方式的兼容性。

### B：仅链接官方来源

项目只提供权利人或官方项目页面/下载页面的来源链接，不镜像、不重新打包、不格式转换。NonCommercial 资源原则上不由项目镜像、打包或转换；只有官方条款允许链接时，才可考虑归入 B。

### C：暂不收录

许可证、来源、权利人、数据库权利、文本版权、转换权或权利链不清。等待可靠的官方依据和复核，不因“免费”“个人使用免费”或能够下载而推定再分发权。

### D：禁止收录

明确禁止分发、来源疑似侵权、疑似盗版、无法确认权利人，或存在无法满足的许可条件。此类资源不镜像、不链接下载、不转换、不打包。

## 审核原则

1. 允许使用或读取不等于允许镜像。
2. 个人免费使用不等于允许项目再分发。
3. 格式转换可能构成修改，必须明确确认转换权。
4. 数据库许可证、词典文本版权和转换工具的软件许可证互不替代。
5. 论坛帖子、第三方下载站、网盘或聚合站不能单独作为权利依据。
6. 审核优先使用权利人或官方项目发布的许可证、条款和下载页面。
7. 许可证或官方条款变更后应重新审核并更新最后复核日期。

本阶段不推荐、收录、下载或测试任何实际词库。
